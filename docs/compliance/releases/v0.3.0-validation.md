## 6. Regulated-data handling

No compliance profile is declared; the strict PHI/PII lens was applied to
the change anyway (opuspopuli-side `/op-data-scan`, 2026-08-22): no
critical/high exposure findings. Specifics for this service: the request
audit log (`prompt_request_log`) stores endpoint/version/key-prefix/region
only — no DTO fields, so declared signals are never persisted here; test
fixtures are synthetic; in the primary consumption path (opuspopuli
prompt-client remote-cache mode) only the *template* crosses this service's
boundary — interpolation with user signals happens in the caller's process,
inside the platform's self-hosted trust boundary.
