## 6. Regulated-data handling

No profile is declared, so the strict lens was applied. No template asks for
or echoes personal data. #122 reduces the risk of invented facts about named
public figures.

## 7. Deploy

Before opuspopuli `v2.0.0` (cutover runbook W4):

1. Seed once.
2. **Do not restart the container after seeding.** Its boot re-seed from the
   image can overwrite newer template text while leaving the version number
   unchanged.
3. Verify each template's version and hash against `prisma/seed.ts`.
